# 回页 · AI Diary

一款能随时随地无负担记录思考，并让过去与现在重新连接起来的 AI 原生记录产品。

> 轻量，先有用，后回味。

## 产品定位

回页不是“给日记加一个 AI 聊天框”，而是一个**思考连续性系统**：用户只负责记录，不必维护复杂知识库；过去尚未结束的思考，会在未来合适的时刻重新接上。

AI 默认克制。它负责带回证据、建立关联、接住情绪并轻轻询问，不替用户定义自己。

## 当前版本

当前仓库包含可交互 MVP：

- 弹性写作画布与长文聚焦模式；
- 日记池、搜索、查看、编辑和删除；
- 标签管理、文本粘贴与图片附件；
- 单篇及多篇 Markdown 导出；
- “AI 整理”和“AI 关联”两个独立权限；
- 模拟 AI 整理、对话召回和思考回环；
- 浏览器本地数据保存。

在线体验：[huiye-ai-diary.zhenghengchen13.chatgpt.site](https://huiye-ai-diary.zhenghengchen13.chatgpt.site)

> 当前 AI 能力使用模拟逻辑。下一阶段将依次实现正式数据底座、真实 AI 整理、主动 RAG、思考回环和确认式记忆。

## 核心产品原则

- 写作是视觉中心，工具退后。
- 原文永远保留，AI 产物不能静默覆盖。
- AI 整理与 AI 关联是两个独立权限。
- 主动召回准确之后，才开发被动提醒。
- 记忆不复制文档，只保存交流中经过用户确认的理解。
- 用户可以查看、修改、删除 AI 形成的摘要和记忆。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
pnpm install
pnpm dev
```

构建检查：

```bash
pnpm build
```

## 当前技术栈

- TypeScript
- React
- Next.js / Vinext
- Cloudflare Workers / Sites
- 浏览器 Local Storage（当前 MVP）

规划中的正式数据层为 D1、R2、FTS5 与 Vectorize；AI 层采用模型可替换的 Responses API 与 Embeddings 架构。

## 路线概览

1. 可靠的普通日记：草稿、版本、导入、回收站、筛选和云端数据。
2. 真实 AI 整理：标题、格式、标签、OCR 纠错和问题提取。
3. 主动对话召回：关键词＋向量混合检索、权限过滤和来源引用。
4. 思考回环：连接旧疑问、真实反馈与新理解。
5. 确认式记忆与稀缺主动提示。

详细计划见 [ROADMAP.md](./ROADMAP.md)。
