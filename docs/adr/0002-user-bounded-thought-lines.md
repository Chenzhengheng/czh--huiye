# ADR-0002：以用户约束的思考线作为 AI 回响边界

- 状态：Accepted
- 日期：2026-08-08
- 取代：ADR-0001 的核心机制

## 背景

全局 AI 寻找联系会把“哪些记录属于同一场思考”的判断外包给模型，成本高、频率低、收益未知，也容易得到正确而无感的结果。用户需要及时看清已经隐约记录的变化，同时保留主导权。

## 决策

ThoughtLine 成为用户主动创建的一等对象，一篇 Entry 可选择性加入多条线。AI 的正式回响当前只在线内产生，引用至少两篇原文并显化延续、修正、分支、冲突或未解决问题。未归线和跨线内容只留给未来用户明确启动的低频复盘。

## 取舍与后果

获得明确意图边界、较低审视成本、可解释证据和真实权限；付出一次轻量归线、早期网络稀疏和遗漏少量跨领域联系。ThoughtLine 因此需要稳定 ID、生命周期、合并与权限；旧单页回看和无共同线关系降为 `legacy_evaluation`；成功主质量改为显化价值；先积累案例再设计生产 Prompt。
