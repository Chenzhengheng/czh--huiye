# ADR-0003：为不可变 generation 设置分层保留边界

- 状态：Accepted
- 日期：2026-08-13

## 背景

回页每次自动保存都会写入一个完整、不可变的 generation。这保证了中断恢复与历史可读性，但在高频写作时也会把相同的几十篇 Entry 重复保存数百次，使 `local-data/generations/` 和 pointer history 无界增长。直接只留最新版本会失去恢复价值，永久保存所有版本则会持续放大磁盘占用与维护成本。

## 决策

保留当前 generation、最新 20 个 generation、最近 30 天每天最后一个 generation，以及更早历史每月最后一个 generation。自然日与自然月按 `Asia/Shanghai` 计算。清理只发生在一次保存已完整完成并切换 current pointer 之后；失败不得影响保存结果。首次实际删除前，必须导出并重新校验当前完整 JSON 备份，同时移除指向已删除 generation 的 pointer history。

自动流程每次保存后检查，但每天至多实际清理一次；维护脚本可以显式强制执行同一策略。PortfolioMode 不接触私人 generation。

## 取舍与后果

该策略保留密集的近期撤回能力和稀疏的长期恢复点，并停止目录无界增长；代价是被清理的中间版本不可逐个恢复。首次清理备份可以恢复清理发生时的完整当前状态，但不承诺保存所有被删除的历史快照。保留规则因此必须进入数据契约、测试和维护脚本，未来若调整边界应显式更新本 ADR。
