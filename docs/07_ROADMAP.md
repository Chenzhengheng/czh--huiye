# 回页：产品路线图

> 当前阶段：用真实 case 冻结回响规则与数据契约
> 最后更新：2026-08-05

## 产品质量目标

回页的核心质量是：用户明确反馈中的重逢感。保存新 Entry 是可选的深层结果，不是唯一成功。

约束：

- 不通过增加频率制造成功数量；
- 沉默保持未知；
- 没有合格候选时保持安静；
- 不把点击、停留或继续写单独当成重逢感。

- [ ] 确认 reason codes 是否足够区分“错误”和“正确无感”。

### 2. 候选发现 Prompt

- [ ] 区分自我表达与纯理论知识；
- [ ] 要求所有关系由原文证据核验；
- [ ] 判断内容是否仍在用户当前认知中；
- [ ] 排除只复述近期已说完结论的候选；
- [ ] 不以情绪浓度替代重逢价值；
- [ ] 输出联系、变化或张力候选，不输出人生定论；
- [ ] 用真实 case 做版本化回归。

### 3. 解释性初判 Prompt

- [ ] 原文先于 AI；
- [ ] 给出有方向但可修正的初判；
- [ ] 不强迫原因分析或二选一诊断；
- [ ] 问题可选，不以产出新 Entry 为目标；
- [ ] 记录 Prompt、规则和模型版本。

### 4. 调度与反馈规则

- [ ] 冻结最短时间错位、近期重复与冷却规则；
- [ ] 每次只派生一个当前候选，不暴露候选数量；
- [ ] 一次结束后不立即补下一条；
- [x] 实现三类可选反馈的兼容事件与当前界面；
- [ ] “正确而无感”只否定本次呈现；
- [ ] “不太对”按明确范围校准。

## 暂不做

- AI Chat 作为产品主入口；
- 多用户、社交或公开社区；
- 跨设备自动同步；
- 人格分析、心理诊断或自动人生总结；
- 独立理论知识库或知识图谱；
- 无限回响列表、未读计数或连续刷下一条；
- 为了指标高频推送；
- 专属模型训练；
- 在 v2 验收前清理唯一可恢复旧数据。
